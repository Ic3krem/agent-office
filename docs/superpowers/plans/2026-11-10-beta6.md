# beta.6: sign-ins, town HUD, music, manor themes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Users get going with Codex/Gemini/OpenCode and Claude without Build mode or a terminal, and the town gets a HUD (tasks, graphics, build, party chat bubbles, music, manor) with background music, a synced party music player and manor themes friends can see.

**Architecture:**
- Pure node modules hold every rule that can be tested: `cli-auth.mjs` (sign-in probes, login commands, terminal argv), `claude-key.mjs` (API key shape, hint, encrypted file), `music.mjs` (folder listing, file lookup, range, prefs). Party rules (music links, manor) go into `party/protocol.mjs` so the party server and the app share them.
- Browser modules are classic UMD scripts in `public/` (testable through `world-vm.mjs`): `manor.js` (presets, palettes, building + tint), `bg-music.js` (generative WebAudio + folder player), `party-music.js` (shared player, sync maths), `hud.js` (floating panels shared by the town and the office: tasks, graphics, build, party, music, manor, Claude).
- Everything that sets a secret or a path goes through desktop IPC (`desktop/main.mjs` + `desktop/office-preload.cjs`), never a server route.

**Tech Stack:** Node ESM, node:test, Electron 43 (safeStorage, dialog, BrowserWindow), WebAudio, YouTube/Spotify embeds driven by postMessage (no remote scripts).

**Spec:** `docs/superpowers/specs/2026-11-10-beta6-settings-town-hud-music-manor-design.md`

## Global Constraints

- No `shell: true`; the terminal opener builds argv only from resolved paths and fixed args.
- Probes: 5 s timeout, cached 60 s, never print tokens. Codex `codex login status` exit 0; Gemini env `GEMINI_API_KEY`/`GOOGLE_API_KEY`/`GOOGLE_GENAI_USE_VERTEXAI`/`GOOGLE_GENAI_USE_GCA` or `~/.gemini/settings.json` `security.auth.selectedType` (or top-level `selectedAuthType`); OpenCode `opencode auth list` non-empty, unknown = "uses its own config".
- Add desk: next free `ext-<cli>-<n>` (n 1..3), disabled at 3 per CLI or when the CLI is not installed; same validation as Build mode.
- API key: `sk-ant-` shape, `CFG_DIR/claude-key.enc` (0600) via safeStorage, mode switch "Use: Claude account | API key", page sees only `key set · ends …abcd`. Never logged, never in kiro.json, never in a party. safeStorage missing → key option disabled with the reason. The key is not passed to external CLIs.
- Music prefs kiro.json `music: {bg: 'builtin'|'folder'|'off', volume, folder}`; folder only via the desktop dialog; files mp3, ogg, m4a, wav, flac; at most 2 levels deep; at most 2000 files; served by index with range requests. Duck −12 dB under party music; pause when hidden.
- Party `music`: `{src: 'youtube'|'spotify'|'stream', ref, title?, startedAt, paused, pos}`, server-stamped. youtube id `/^[\w-]{11}$/`; spotify `track|album|playlist|episode` + `/^[A-Za-z0-9]{22}$/`; stream `https://`, ≤ 300 chars, no credentials. Host plus "anyone can DJ" (default on). Rate limit like chat. Late join seeks to `now − startedAt + pos`; resync when drift > 2 s.
- CSP: add `frame-src https://www.youtube-nocookie.com https://open.spotify.com` and `media-src https:`; nothing else widened (so no remote script: embeds are driven by postMessage).
- Manor kiro.json `manor: {theme, colors: {wall, floor, roof, accent}}`; presets modern, country, japanese, beach (modern), cyber (modern), cottage (country); colors `#rrggbb`. Party feed carries theme + 4 colors only.
- HUD: top right of town.html, ≥44px targets, one panel at a time, Esc closes. Chat bubble fades after ~6 s, max 140 chars.
- Repo is public: no personal names, emails or user paths in code, tests or fixtures (use example.com).
- Every new test file goes into the `npm test` list. No new npm dependencies.
- Live tests: temp USERPROFILE/HOME/APPDATA/LOCALAPPDATA, ports 4790–4799 (never 4795), `AGENT_OFFICE_NO_TUNNEL=1`; never `claude auth login/logout` for real; never open a real terminal.
- Commit trailer: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` / `Claude-Session: https://claude.ai/code/session_01PNVRsJVAb8TMWQTrE5T7gv`.

## Review Focus

1. **A path escape through the music file route** (`i` out of range, a symlink or a file renamed after listing): 404, never a file outside the folder. Test in Task 6.
2. **A pasted link that is not what it claims** (`https://user:pw@…`, `javascript:`, a YouTube id of 12 chars, a Spotify `artist` link): rejected by the cleaner on both sides. Test in Task 4.
3. **A guest who is not the DJ sends music while "anyone can DJ" is off**: refused, nothing relayed. Test in Task 5.
4. **A login CLI that is not installed or is an unrecognised shim**: no spawn, the page gets the command to copy. Test in Task 1.
5. **A manor colour in another form** (`red`, `#fff`, `url(...)`): dropped, the preset colour used. Test in Task 4.
