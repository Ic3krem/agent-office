Privacy: what a download records

This site has no cookies, no analytics and no trackers. Pressing the download button goes through a small counter that records only: your country (and continent), the date (UTC), the app version, and your browser family (for example Chrome or Firefox). To count each person once it keeps a keyed, one-way hash made from your network address. Your IP address itself is not stored or logged, and neither is your full browser string. The numbers are used to count early-access downloads by region and to enforce the limit of 500 early-access downloads. Because a hash made from an IP address can still count as personal data in some countries, it is kept only for that purpose. If you would rather not be counted, do not use the download button.

Windows SmartScreen. The build is not code-signed, so Windows may show "Windows protected your PC". Check the SHA-256 below first. If it matches, choose More info, then Run anyway.

Install steps

  1. Install Claude Code and run claude once to log in. Agent Office uses your own install and plan.
  2. Download the installer with the button above.
  3. Verify it. In PowerShell, from the folder you saved it in, run Get-FileHash .\Agent-Office-Setup-VERSION.exe -Algorithm SHA256 and compare the result with the SHA-256 shown above.
  4. Run the installer. It is a normal setup wizard where you pick the folder, and it adds a Start menu entry and a desktop shortcut.
  5. Open Agent Office from the shortcut. Double-click Tiro, or use the tray menu and choose Open office.

Requirements: Windows 10 or later, and Claude Code installed and logged in.

How it is distributed

While the source repository is private, a release page may need access you do not have. Installers sent to you directly can be checked with the SHA-256 shown above. The in-app updater and the install scripts verify an Ed25519 signature on the release manifest as well as the installer's SHA-256, and stop if either check fails. See Install and Update.
