Troubleshooting and FAQ

Common problems and short answers.

Troubleshooting

ProblemWhat to try
Dashboard is blankReload. If it persists, check the app is up to date (older builds before 1.2.5 could not load their scripts under the security policy).
"Connecting" banner staysThe server is not running. Restart Agent Office. If another copy holds the port, quit it first.
401 "not signed in" from a scriptThe API needs the UI session cookie, which only the desktop app (or the one-time sign-in link of a standalone run) has. The bridge key in bridge.json opens /bridge/* only.
Tiro does nothingCheck the Breaker box (Tiro on, plan guard not paused) and that Claude Code is installed and logged in.
Far more (or fewer) prompts than beforePrompts now follow your Claude Code permission rules and mode; edit your allow, deny and ask rules or permissions.defaultMode (permissions.md).
Hire card never appearsHiring switch may be off, or Tiro asked for a goal that is not open.
Scheduler says "no data yet" or "No mail feed file yet"The job has not run, or nothing writes inbox-feed.json. See scheduler.md.
SmartScreen warns on installThe build is not code-signed. Compare the SHA-256 with the one on the GitHub release.
Update refusedThe feed has no SHA-256, or the hash did not match.

FAQ

Does the office cost tokens? No. Only agents working cost tokens, and only on your Claude Code plan.

Can an agent hire without asking me? No. Every hire needs your one-shot approval.

Where is my data? On your machine: ~/.claude/agent-office, your vault, and Claude Code's own ~/.claude/projects. Model calls go to Anthropic through Claude Code, as in the terminal.

Does it read my email? No. The scheduler reads a local feed file that you must produce yourself.

Can I rename agents and keep their history? Yes; history follows the type, not the name.

Why a vendored React and Babel? So the dashboard works under a strict security policy and fully offline; the fonts are vendored too.
