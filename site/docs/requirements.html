    Requirements

    What you need before installing.

    Written for v2.1.0 · updated 2026-11-20

    TiroAgents needs:

    • Windows 10 or later, macOS (Apple silicon or Intel) or Linux (x64, AppImage or .deb).
    • Claude Code installed and logged in (run claude once). TiroAgents uses your own Claude Code install and plan.
    • Disk space for the installer (about 104 MB) and your notes and reports.

    Nothing else is required. The office uses no tokens. Models only run while an agent works, through your own Claude Code plan.

    The builds are not code-signed, so Windows may show a SmartScreen warning, Windows 11 Smart App Control may block the installer and macOS may refuse to open the app until you allow it. See Troubleshooting.
