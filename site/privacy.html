Privacy

This site sets no cookies and shows no consent banner, because it does not need one.

What this site does

  • It sets no cookies and stores nothing in your browser.
  • It loads no remote fonts, scripts, images or trackers. Everything comes from this site's own files, including the 3D library on the home page.
  • No analytics are enabled right now.
  • The download buttons go through this site's download counter at tiroagents.bmos.website, which then sends you to the file on GitHub. GitHub receives that request under its own privacy terms.

The download counter

  • Each download is recorded as one row: a keyed hash of your IP address, the file, the UTC day, your country and its world region (North America, South America, Europe, Africa, Asia or Oceania), as reported by the network edge.
  • Your IP address is used only as the input to that keyed hash (HMAC-SHA-256 with a secret key, shortened to 128 bits), so that the same file downloaded again on the same day counts once. The address itself is never stored or logged, and the hash cannot be turned back into it without the key.
  • Only totals per system and per region are published. Per-country numbers are never shown.
  • No cookies, no identifiers in the link and nothing about the page you came from are kept.
  • The home page reads the totals from tiroagents.bmos.website/stats; that request carries no data about you beyond what any web request does.

Download statistics

The statistics page shows GitHub's own installer download counts per release. Nothing about visitors is collected or stored there. See the method note on that page.

The app itself

TiroAgents keeps its state on your computer. Model calls go to Anthropic through your own Claude Code install, as in the terminal. Other network use includes the signed update check and, if you turn it on, synced lyrics lookups (title, artist, album and duration only). In a party's meeting room, voice goes directly between the apps in the room: nothing is recorded, the party server only passes connection setup messages, and the people in the room and the public STUN servers (stun.l.google.com, stun.cloudflare.com) can see your IP address. Listen only never opens your microphone; an optional relay (TURN) server you set yourself carries the call when a network blocks direct ones. See the party page and the security page.
