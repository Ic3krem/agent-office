    Verify the download

    Open PowerShell in the folder where you saved the installer and run:

    Get-FileHash .\Agent-Office-Setup-1.2.8.exe -Algorithm SHA256

    The result must equal the SHA-256 above, letter for letter. If it does not, delete the file and do not run it.

    Windows warnings

    The installer is not code-signed, so Windows may warn you. That is expected for an unsigned build. Check the SHA-256 first.

    SmartScreen. You may see "Windows protected your PC". If the SHA-256 matches, choose More info, then Run anyway.

    Windows 11 Smart App Control. If Smart App Control is on, Windows may block an unsigned installer with no Run anyway option. You can look at the setting in Windows Security under App and browser control, Smart App Control settings. Turning it off can be permanent on some Windows 11 versions, so decide deliberately. If you cannot accept that, do not install the unsigned build. See also Troubleshooting.

    Install steps

    1. Install Claude Code and run claude once to log in. Agent Office uses your own install and plan.
    2. Download the installer with the button above.
    3. Verify its SHA-256 as shown above.
    4. Run the installer. It is a normal setup wizard where you pick the folder, and it adds a Start menu entry and a desktop shortcut.
    5. Open Agent Office from the shortcut. Double-click Tiro, or use the tray menu and choose Open office. Then follow the quickstart.
