Privacy

This site sets no cookies and shows no consent banner, because it does not need one.

What this site does

  • It sets no cookies and stores nothing in your browser.
  • It loads no remote fonts, scripts, images or trackers. Everything comes from this site's own files.
  • No analytics are enabled right now.
  • The download link goes to GitHub. GitHub receives your request under its own privacy terms, and shows an installer download count per release.

Download statistics

The statistics page publishes only a country-level snapshot. No IP addresses are stored. See the method note there.

The app itself

Agent Office keeps its state on your machine. Model calls go to Anthropic through your own Claude Code install, as in the terminal. Other network use includes the signed update check and, if you turn it on, synced lyrics lookups (title, artist, album and duration only). See the security page.
