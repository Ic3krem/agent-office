Method

A scheduled job reads GitHub's own download count for each release file and rebuilds this page. Only installers count (.exe, .dmg, .AppImage, .deb); update metadata and block maps do not. The app's built-in updater downloads the same installer, so updates are included, and one person who downloads twice counts twice. GitHub publishes no location or visitor data, and this site collects none.
