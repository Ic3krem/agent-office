Method

A scheduled job reads GitHub's own download count for each release file and rebuilds this page every six hours. Only installers count (.exe, .dmg, .AppImage, .deb); update metadata and block maps do not. The app's built-in updater downloads the same installer, so updates are included, and one person who downloads twice counts twice. The totals include 42 downloads from the project's earlier repository, frozen when it closed. GitHub publishes no location or visitor data, and this page collects none. The map on the home page uses the site's own download counter, which keeps a count per region only; see the privacy page.
