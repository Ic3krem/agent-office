    Troubleshooting

    Windows warnings and common problems.

    Written for v1.2.8 · updated 2026-11-04

    SmartScreen and Smart App Control

    The installer is not code-signed. Compare its SHA-256 with the one on the download page before you run it.

    • SmartScreen may show "Windows protected your PC". If the SHA-256 matches, choose More info, then Run anyway.
    • Smart App Control (Windows 11) can block an unsigned installer and offer no Run anyway option. It is a Windows setting under Windows Security, App and browser control, Smart App Control settings. Turning it off can be permanent on some Windows 11 versions, so decide deliberately. If you cannot accept that, do not install the unsigned build.

    Troubleshooting

    ProblemWhat to try
    Dashboard is blankReload. If it persists, check the app is up to date (older builds before 1.2.5 could not load their scripts under the security policy).
    "Connecting" banner staysThe server is not running. Restart Agent Office. If another copy holds the port, quit it first.
    401 "not signed in" from a scriptThe API needs the UI session cookie, which only the desktop app (or the one-time sign-in link of a standalone run) has. The bridge key in bridge.json opens /bridge/* only.
    Tiro does nothingCheck the Breaker box (Tiro on, plan guard not paused) and that Claude Code is installed and logged in.
    Far more (or fewer) prompts than beforePrompts now follow your Claude Code permission rules and mode; edit your allow, deny and ask rules or permissions.defaultMode (Permissions and Claude Code parity).
    Hire card never appearsHiring switch may be off, or Tiro asked for a goal that is not open.
    Scheduler says "no data yet" or "No mail feed file yet"The job has not run, or nothing writes inbox-feed.json. See Scheduler.
    SmartScreen warns on installThe build is not code-signed. Compare the SHA-256 with the one on the GitHub release.
    Update refusedThe feed has no SHA-256, or the hash did not match.
