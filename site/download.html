    Open PowerShell in the folder where you saved the installer and run:

    Get-FileHash .\TiroAgents-Setup-2.1.0.exe -Algorithm SHA256

    The result must equal the SHA-256 above, letter for letter. If it does not, delete the file and do not run it. On macOS and Linux, the install script verifies the Ed25519 signature on the release manifest and the file's SHA-256 before it installs anything.

    Warnings when you install

    The installers are not code-signed, so your system may warn you. That is expected for an unsigned build. Check the SHA-256 first.

    Windows SmartScreen. You may see "Windows protected your PC". If the SHA-256 matches, choose More info, then Run anyway.

    Windows 11 Smart App Control. If Smart App Control is on, Windows may block an unsigned installer with no Run anyway option. You can look at the setting in Windows Security under App and browser control, Smart App Control settings. Turning it off can be permanent on some Windows 11 versions, so decide deliberately. If you cannot accept that, do not install the unsigned build. See also Troubleshooting.

    macOS Gatekeeper. The app is not signed by Apple, so macOS may refuse to open it. The install script clears the quarantine flag for you; after a manual install, use Open Anyway in System Settings, Privacy and Security.

    Install steps

    1. Install Claude Code and run claude once to sign in. TiroAgents uses your own install and plan.
    2. Download the file for your system and verify it as shown above.
    3. Windows: run the setup wizard, which adds a Start menu entry and a desktop shortcut. macOS: open the .dmg and drag TiroAgents to Applications. Linux: make the AppImage executable and run it, or install the .deb.
    4. Open TiroAgents. Double-click Tiro, or use the tray menu and choose Open office. Then follow the quickstart.
