Quickstart

From download to your first finished task. About ten minutes.

  1. Get Claude Code ready

    Install Claude Code and run claude once so you are logged in. Agent Office runs on your own install and plan. The office itself costs no tokens.

  2. Download and verify

    Get the installer from the download page, then compare its SHA-256 with the one shown there. The build is not code-signed, so read the Windows warning notes first.

  3. Install and start

    Run the setup wizard. Open Agent Office from the desktop shortcut. Tiro appears on your desktop. Double-click Tiro, or use the tray menu and choose Open office.

  4. Give Tiro a task

    Type a task in the dispatch box, for example "Review the README and list any wrong claims". It is added to today's board as a goal.

  5. Approve the hire

    Tiro asks to hire a specialist. A card shows the goal and the reason. Choose Approve hire or Deny. One approval buys one hire and expires after 10 minutes.

  6. Answer prompts, read the report

    Prompts that Claude Code would show you appear in the dashboard and the island. When the work is done, Tiro files a report you can open and export to PDF or Excel.
