A country is listed only when it has at least 10 downloads. Everything else is grouped as Other. Nothing finer than a country is ever published.

Method

Planned method, not yet running: a download is counted when the Download button is used, not when the page loads. Unique means unique by a hash of the visitor's network, so no IP address is stored. Bots and HEAD requests are excluded. A scheduled job writes stats.json, and this page is rebuilt from it. Until a real snapshot exists the file is marked as sample data.

As a fallback with no regional data, GitHub shows an installer download count for each release asset on the release page, labelled there as GitHub's own count.

Who is responsible for this data, how to reach them and how long it is kept are on the privacy page.
